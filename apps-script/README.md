# Google Apps Script 버전 (PC 안 켜도 되는 방법)

같은 감시를 **구글 서버에서** 돌립니다. 내 컴퓨터는 꺼져 있어도 됩니다.

|  | Apps Script (이 폴더) | Python (`wedding_watch/`) |
|---|---|---|
| 돌아가는 곳 | 구글 서버 | 내 PC 또는 내 서버 |
| PC 켜둬야 하나 | **아니오** | 예 |
| 설치 | 복사·붙여넣기 5분 | 파이썬 설치 필요 |
| 비용 | 무료 | 무료 |

> ⚠️ **먼저 알아둘 것**: Apps Script는 **구글(주로 미국) 서버 IP**에서 사이트에 접속합니다.
> 사이트가 국내 IP만 허용한다면 이 방법은 동작하지 않습니다.
> 아래 **4단계에서 그것부터 확인**하게 되어 있으니, 설치를 끝까지 하기 전에 4단계 결과를 꼭 보세요.

---

## 설치 (5단계)

### 1. 폰에 ntfy 앱 설치 + 토픽 정하기

[iOS](https://apps.apple.com/app/ntfy/id1625396347) / [Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy)

앱을 열고 **토픽(Topic)** 을 하나 구독합니다. 이름은 **남이 절대 못 맞출 임의 문자열**로 하세요.

```
예: swed-geum-3f9a12c7be04
```

> 🔒 ntfy 토픽은 **이름만 알면 누구나 구독(내 알림 엿보기)하고 발행(가짜 알림 보내기)** 할 수 있습니다.
> 비밀번호라고 생각하세요. 남에게 보여준 적이 있다면 새 이름으로 바꾸고 앱에서 다시 구독하세요.

### 2. 스크립트 만들기

1. [script.google.com](https://script.google.com) 접속 → **새 프로젝트**
2. 왼쪽 위 프로젝트 이름을 `웨딩홀 빈자리 알림` 등으로 변경
3. 편집기의 기본 코드를 **전부 지우고**, 이 폴더의 [`Code.gs`](Code.gs) 내용을 **전부 복사해 붙여넣기**
4. 💾 저장 (Ctrl+S / Cmd+S)

### 3. 토픽 등록하기

왼쪽 **⚙️ 프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**

| 속성 | 값 |
|---|---|
| `NTFY_TOPIC` | 1단계에서 정한 토픽 이름 |

**저장**을 누릅니다.

> 코드 안의 `NTFY_TOPIC_FALLBACK` 에 직접 적어도 동작하지만, 그러면 코드를 공유·백업할 때 토픽이 같이 새어 나갑니다. 스크립트 속성 쪽을 권합니다.

### 4. 테스트 — 여기서 되는지 안 되는지 판가름납니다

편집기 위쪽 함수 선택 상자에서 **`sendTestPush`** 를 고르고 **▶ 실행**.

처음 실행하면 구글이 권한을 묻습니다 → *권한 검토* → 본인 계정 선택 →
*"Google에서 확인하지 않은 앱"* 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동** → **허용**.
(내가 방금 만든 내 스크립트라서 나오는 경고입니다.)

아래 **실행 로그**를 확인하세요.

**✅ 잘 된 경우**

```
ntfy 응답: 200 / {"id":...}
ntfy 전송 성공
세션 쿠키 발급 성공
2027-05 원본 days: {"1":{"closed":true},"2":{"closed":true},...
2027-05 → 열린 날: 없음(전부 마감)
2027-06 → 열린 날: 2027-06-07
...
```

폰에도 테스트 알림이 떠야 합니다. **원본 days 로그**를 한 번 훑어보세요 — `closed` 라는 항목이
보이면 정상입니다. 다른 이름(`soldout`, `able` 등)만 보인다면 사이트가 형식을 바꾼 것이니 알려주세요.

**❌ 안 되는 경우**

| 로그 | 뜻 | 대응 |
|---|---|---|
| `세션 쿠키 발급 실패` | 사이트가 구글 서버 IP를 막음 | Apps Script로는 불가. [Python 버전](../README.md)을 쓰세요 |
| `응답이 JSON이 아님(차단 의심)` | 로그인 페이지가 돌아옴 | 위와 같음. 또는 사이트가 로그인을 요구하게 바뀜 |
| `ntfy 응답: 4xx` | 토픽 이름 문제 | 3단계 `NTFY_TOPIC` 값 확인 |
| 아무 로그도 없음 | 권한 승인이 안 끝남 | 다시 ▶ 실행해서 권한 허용 |

### 5. 자동 실행 켜기

함수 선택 상자에서 **`createTrigger`** 를 고르고 **▶ 실행**.

로그에 `10분마다 실행되는 트리거를 만들었습니다.` 가 나오면 끝입니다.
왼쪽 **⏰ 트리거** 메뉴에서 확인할 수 있습니다.

**첫 자동 실행 때는 지금 열려 있는 날짜를 한 번에 알려줍니다.** (현재 상태를 알려주는 것이고, 그 다음부터는 새로 생긴 날짜만 알립니다.)

## 어떤 알림이 오나요

| 알림 | 언제 | 우선순위 |
|---|---|---|
| 🎉 `삼성금융연수원 빈자리 N건` | 새 빈자리가 나왔을 때 | urgent |
| ⚠️ `빈자리 확인 실패 3회 연속` | 30분 넘게 확인 자체가 안 될 때 | high |
| ✅ `감시 복구됨` | 다시 정상으로 돌아왔을 때 | low |
| 💓 `삼성금융연수원 감시 중` | 하루 한 번, 살아있다는 신호 | min |

**⚠️ 알림이 왜 중요한가**: 알림이 안 오는 상태에는 두 가지가 있습니다 — *빈자리가 없어서* 와
*확인 자체가 망가져서*. 둘을 구분 못 하면 망가진 채로 몇 주가 지나갑니다.
그래서 이 스크립트는 **실패했다는 사실 자체를 알립니다.**

💓 하트비트가 성가시면 `Code.gs` 위쪽의 `HEARTBEAT_HOURS` 를 `0` 으로 바꾸세요.
다만 **구글이 트리거를 비활성화하면 실패 알림조차 못 오므로**, 켜 두는 쪽을 권합니다.

## 바꾸고 싶을 때

`Code.gs` 맨 위 세 줄만 고치고 저장하면 됩니다.

```js
var NTFY_TOPIC_FALLBACK = '';                 // 스크립트 속성을 쓰면 비워 둡니다
var HALL_CODE = '5';                          // 5 = 삼성금융연수원
var MONTHS = ['2027-05', '2027-06', ...];     // 노리는 월
```

| 하고 싶은 것 | 방법 |
|---|---|
| 확인 주기 바꾸기 | `createTrigger` 안의 `everyMinutes(10)` 수정 후 다시 실행 |
| 알림 기억 지우기 (처음부터 다시) | `resetState` 실행 |
| 잠시 멈추기 | 왼쪽 **⏰ 트리거** → 해당 트리거 → ⋮ → **트리거 삭제** |
| 지금 당장 한 번 확인 | `checkOpenings` 실행 |

## 이 버전이 특별히 신경 쓴 것

| 상황 | 어떻게 처리하나 |
|---|---|
| 일부 달만 조회 실패 | 실패한 달은 **이전 상태를 그대로 유지**. 상태가 날아가서 같은 날짜를 다시 알리는 일을 막습니다 |
| 전체 조회 실패 | 상태를 **건드리지 않고** 실패만 기록. 3회 연속이면 점검 알림 |
| 응답 형식이 바뀌어 전부 '열림'으로 보임 | 한 달 20일 넘게 열리면 의심하고 **날짜를 쏟아내지 않고** 점검 알림만 |
| 세션 쿠키 발급 실패 | 빈 쿠키로 계속 진행하지 않고 즉시 실패 처리 |
| 실행이 겹침 | `LockService` 로 한 번에 하나만 |
| 규칙적인 접속 패턴 | 매 실행을 0~90초 무작위로 늦춤 |
| 한글·이모지 알림 제목 | ntfy 헤더 제약(latin-1) 때문에 RFC 2047 로 인코딩 |
