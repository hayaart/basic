# 윈도우 버전 (집 데스크톱에서 돌리기)

사이트가 **구글 서버 주소(Apps Script)를 차단**해서, 집 인터넷 주소로 접속하는
윈도우 데스크톱에서 돌립니다. 설치 프로그램은 필요 없습니다 (윈도우 기본 PowerShell).

- 20분마다 **삼성금융연수원** 빈자리 확인 → 새로 나오면 텔레그램 알림
- 텔레그램에 아무 말이나 보내면 현황 + **예식장 버튼** → 눌러서 즉시 조회
- `서초` / `금융` / `E&A` 처럼 **이름을 적어 보내도** 같게 동작합니다

## ⚠️ 저장할 때 꼭 지킬 것 — 인코딩

PowerShell 5.1(윈도우 기본)은 **BOM 없는 UTF-8 을 한글로 못 읽습니다.** 한글이 전부 깨집니다.

- 이 폴더의 파일을 **그대로 내려받아 쓰는 것이 가장 안전합니다** (BOM 포함해 저장해 두었습니다)
- 메모장으로 새로 저장해야 하면 인코딩을 **`UTF-8 (BOM)`** 으로 고르세요.
  (최신 윈도우 메모장은 `UTF-8` 과 `UTF-8 (BOM)` 이 따로 있습니다 — 전자를 고르면 깨집니다)

## 봇 토큰은 스크립트에 적지 마세요

스크립트와 같은 폴더가 아니라 **아래 경로에 따로** 두는 것을 권합니다.
실수로 파일을 공유하거나 저장소에 올려도 토큰이 새지 않습니다.

`%LOCALAPPDATA%\wedding-bot.json`

```json
{ "token": "봇토큰", "chatId": "내채팅ID" }
```

> 🔒 토큰이 한 번이라도 노출됐다면 BotFather 에서 **`/revoke`** 로 새로 발급하세요.
> 토큰을 아는 사람은 그 봇으로 메시지를 읽고 보낼 수 있습니다.

## 🚨 꼭 잡고 싶은 날짜 — 전용 봇으로 강하게 받기

`2027-05-22(토)`, `2027-05-29(토)` 처럼 **노리는 날짜**가 열리면 평소 알림과 다르게 받습니다.

```
🚨🚨 노리던 날짜가 열렸습니다 🚨🚨

삼성금융연수원
2027년 5월: 22(토)

지금 바로 신청하세요: https://...

(1/3)
```

**1분 간격으로 3번** 보냅니다. 한 번 놓쳐도 또 울립니다.

### 왜 봇을 따로 파야 하나

텔레그램은 **알림 소리·강도를 "대화방 단위"로만** 정할 수 있습니다. 봇이 메시지마다
소리를 다르게 지정할 방법은 없습니다. 그래서 **진짜로 더 강하게** 받으려면 대화방을
따로 두고, 그 방에만 전용 소리·긴급 중요도·방해금지 예외를 걸어야 합니다.

전용 봇을 안 만들어도 동작합니다 — 평소 봇으로 3번 옵니다. 다만 **소리는 같습니다.**

### 전용 봇 만들기 (5분)

1. 📱 `@BotFather` → **`/newbot`** → 이름 정하기 (예: `웨딩 긴급봇`)
2. 📱 새 봇 대화방을 열어 아무 말이나 한 번 보내기
3. 💻 `%LOCALAPPDATA%\wedding-bot.json` 에 추가:

```json
{
  "token": "평소 알림 봇 토큰",
  "chatId": "내 채팅 ID",
  "hotToken": "긴급 봇 토큰",
  "hotChatId": "내 채팅 ID (같은 숫자입니다)"
}
```

> `hotChatId` 는 **평소와 같은 숫자**입니다. 채팅 ID 는 내 계정 번호이지 봇 번호가 아닙니다.

4. 📱 **그 방의 알림을 가장 강하게** 설정하세요 — 이게 핵심입니다

| | 어떻게 |
|---|---|
| 공통 | 대화방 → 위쪽 봇 이름 → **알림** → **사용자 지정** → 눈에 띄는 소리 |
| 아이폰 | 설정 → 알림 → Telegram → **시간에 민감한 알림 허용** / 집중 모드 허용 앱에 추가 |
| 안드로이드 | 앱 알림 → 해당 채널 **중요도 `긴급`** · 방해 금지 **예외** |
| 둘 다 | 텔레그램 설정 → 알림 → **반복 알림 5분** |

### 날짜 바꾸기

`wedding.ps1` 위쪽:

```powershell
$HotDates      = @("2027-05-22","2027-05-29")
$HotRepeat     = 3     # 몇 번 보낼지
$HotGapSeconds = 60    # 보내는 간격
```

> 💡 응답 형식이 바뀐 것으로 **의심되는 경우에는 긴급으로 올리지 않습니다.**
> 헛울림을 긴급으로 보내면 정작 진짜일 때 믿지 않게 되니까요.

## 쓰는 법 (한 번만)

1. 한 폴더에 **`wedding.ps1`** 과 **`웨딩알림.bat`** 두 파일을 둡니다
2. 위의 `wedding-bot.json` 을 만들어 토큰과 채팅 ID 를 넣습니다
3. 📱 텔레그램에서 내 봇과 대화를 시작합니다 (아무 말이나 한 번)
4. **`웨딩알림.bat`** 더블클릭 → **1번(테스트)**
   - 텔레그램에 `🔔 테스트` 가 오고, 창에 `확인한 달=6` 이 나오면 정상입니다
5. **2번(전체 설치)** → 끝. 데스크톱이 켜져 있는 동안 자동으로 돕니다
6. 끄려면 **3번(전체 해제)**

## 설정 바꾸기

`wedding.ps1` 맨 위 `===== 설정 =====` 부분만 고칩니다.

| 값 | 뜻 |
|---|---|
| `$HallCode` | 자동 감시 예식장 — `1` 서초사옥 · `3` 삼성E&A · `5` 삼성금융연수원 |
| `$HallName` | 알림에 쓸 이름 |
| `$Months` | 감시할 달 |
| `$HotDates` | 긴급 알림으로 받을 날짜 |
| `$IntervalMinutes` | 확인 주기 (기본 20분) |

## 안 될 때

| 증상 | 원인 | 할 일 |
|---|---|---|
| 한글이 `ÇÑ±Û` 처럼 깨짐 | BOM 없는 UTF-8 로 저장됨 | `UTF-8 (BOM)` 으로 다시 저장 |
| `확인한 달=0 실패=6` | 사이트가 막음 | 브라우저로 사이트가 열리는지 확인 |
| 텔레그램이 안 옴 | 토큰·채팅 ID | `wedding-bot.json` 값 확인 |
| 봇이 답을 안 함 | 대화봇이 안 돌고 있음 | `웨딩알림.bat` → 2번 다시 |
| 20분 뒤부터 멈춤 | 작업 반복 설정 | 3번 해제 후 2번 재설치 |

## 이 버전이 신경 쓴 것

| 상황 | 어떻게 처리하나 |
|---|---|
| 달력 페이지 열기 실패 | 세션 객체를 미리 만들어, 그래도 조회는 시도합니다 |
| 일부 달만 조회 실패 | 그 달은 **이전 기록을 이어받습니다**. 같은 날짜를 다시 알리는 일을 막습니다 |
| 전부 조회 실패 | 기록을 건드리지 않고, 차단 알림은 6시간에 한 번만 |
| 응답 형식이 바뀐 듯함 | 알림을 막지 않고 제목을 `⚠️ 확인 필요` 로 바꿔 보냅니다 |
| 이름을 적어 보냄 | 버튼을 누른 것과 똑같이 처리합니다 |
